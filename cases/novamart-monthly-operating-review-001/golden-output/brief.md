# NovaMart completed-order review

Completed-order value increased from $381,765.78 in October to $453,073.37 in December, an increase of $71,307.59 or 18.68%. Completed-order count increased 33.03%, from 4,672 to 6,215, while average completed-order value declined 10.79%, from $81.71 to $72.90.

The increase in completed-order count was the primary positive contributor to the net value change. Lower average completed-order value offset part of that gain. NovaMart should first investigate what drove the completed-order count increase and whether it is sustainable, while retaining the decline in average completed-order value as a secondary investigation.

This descriptive analysis does not establish why either metric changed. It uses `order_date` as the governing date and treats `total_amount` as completed-order value.
